# DDHADtens
The present DDHADTENS code extracts variables characterizing anisotropic damage of elastic tensors using harmonic analysis. The program takes as input: (a) an undamaged elastic tensor and (b) a series of damaged elastic tensors. The output is a series of damage variable. 2D and 3D versions are provided, as well as Matlab and Python codes.
